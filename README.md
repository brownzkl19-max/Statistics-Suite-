# Statistics Suite

A responsive, learning-focused statistics workspace for students and independent learners.

## Features

- Descriptive statistics: mean, median, mode, range, variance, standard deviation, quartiles and IQR
- Probability and counting: factorials, permutations and combinations
- Correlation, linear regression and visual charts
- Z-scores, outlier detection, percentiles and frequency tables
- CSV Data Explorer with in-browser previews and numeric summaries
- Formula Library and beginner-friendly Learning Center
- Machine-learning practice calculators: confusion-matrix metrics, data normalization, and regression error metrics
- Altair AI Studio (formerly RapidMiner Studio) learning notes
- Calculation history, responsive mobile navigation, light/dark theme, and installable/offline app-shell support

## Privacy

CSV files are processed in the browser for the Data Explorer; the app does not upload the selected CSV file to a server. Calculation history is stored in the browser on the device.

## Run locally

Open `index.html` in a modern browser. The app is a static HTML/CSS/JavaScript project and does not require a build step.

## Publish

The project can be hosted with GitHub Pages from the `main` branch and repository root. The included `manifest.json` and `sw.js` provide basic PWA metadata and app-shell caching.
